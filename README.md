### Professional Profile

Final-year Computer Science Bachelor's student at ICC Brussels, spécialisé en administration système, infrastructure et sécurité informatique.

À l’aise dans les environnements Windows et Linux, avec des compétences pratiques en virtualisation, supervision, durcissement système, réseau et automatisation.  
Mes projets récents se concentrent sur la mise en place d’environnements hybrides, la sécurisation des systèmes et la supervision d’infrastructures.

Je possède également une expérience académique en développement backend (Java, Spring Boot), utilisée comme compétence complémentaire pour comprendre les applications et API déployées dans les environnements que j’administre.
